# Интерфейс и прокрутка — 06.10.2026

## Что изменено
Единая тёмная палитра, контраст подписей, отступы и карточки сетапов. Главная: наборы колонок Обзор / Потоки и деривативы / Все показатели; компактный режим; сворачивание фильтров. Настройки сохраняются локально в браузере без финансовых данных.

Таблицы: ограниченная высота, вертикальная прокрутка внутри списка, закреплённые заголовки и первая колонка, синхронная горизонтальная полоса сверху. Нет перехвата колеса: масштабирование графика остаётся штатным. Карточки адаптированы к узким экранам без минимальной ширины 330px плюс отступы.

График: слой выше меню, блокировка прокрутки фоновой страницы, ограниченная прокручиваемая панель инструментов и независимый скролл анализа. При закрытии отменяется ожидающий асинхронный запрос отрисовки. Вкладки ботов: автоматическая высота same-origin iframe с ResizeObserver вместо фиксированного 85vh и вложенного вертикального скролла. Попапы меню ограничены высотой экрана.

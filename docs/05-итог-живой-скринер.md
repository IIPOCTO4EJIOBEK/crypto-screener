## Из чего состоит

**Круг скринера** (`tools/live/online.py`, раз в ~4,5 мин): свечи и стаканы
в sqlite, страницы `screener.html`, `structures.html`, `densities.html`,
главная `board.html` (`tools/live/board.py` + шаблон `board.html`),
`trend-now.json` для ботов.

**Процесс свечей** (`tools/live/klines.py`, рядом с кругом, перезапускается им):
- WebSocket `kline_5m/15m/1h` по всему составу (адрес Binance `/market/stream`,
  старый `/stream` молчит) → `kl/<SYM>_<tf>.json` (история) и
  `kl/<SYM>.live.json` (текущая свеча);
- рыночные метрики раз в 2 мин (`market_stats.py` → `kl/stats.json`):
  сделки в минуту, CVD, хай/лой дня и недели, funding и время списания, OI, L/S;
- сверка плотностей со стаканом (`dens_watch.py` → `kl/dens_state.json`):
  стоит / съедена / снята, возраст заявки, размер к 5м обороту;
- открытые позиции ботов → `kl/positions.json`;
- общее меню на всех страницах (`navinject.py`, `nav.js`);
- алерты в Telegram (`alerts.py`, картинки — `alert_chart.py`).

При ответе Binance 418/429 запросы молчат до снятия бана (`market_stats.Banned`).

## Главная страница

- Таблица монет: цена, 1ч/24ч, оборот, NATR, объём к среднему, всплеск за
  сутки, сделки в минуту, до хая/лоя дня и недели, funding с таймером, OI,
  L/S, CVD, корреляция с BTC, ADX, тренд 15м/1ч/4ч, ближайшая плотность
  одной строкой (сторона, размер, расстояние, сколько стоит), мини-график,
  формации; избранное ★ и скрытые ✕.
- Вкладки «Можно торговать» (по тренду своего ТФ, по умолчанию R:R от 1:3),
  «Формации», «Плотности».
- График (lightweight-charts): родные свечи каждого ТФ, обновление 1/3/5 с;
  уровни с подписью ТФ (и уровни 1ч на младших ТФ), наклонные скринера и
  свои по разворотам, продлённые вправо; волны (три толчка), Фибоначчи;
  зона сделки выбранной формации с 1R/2R/3R, перехаем и текущим R; отмена
  формации по закрытию свечи; плотности по порогу; позиции ботов; линейка на
  правой кнопке. Разметка пересчитывается сама, без перезагрузки страницы.
- Ссылка `/#chart=SYMBOL&tf=15m` сразу открывает график монеты (так работают
  ссылки из алертов и из таблиц ботов).

Порог плотностей — `data/dens_rules.json`: показывать от максимального 5м
оборота за 30 мин и простоявшие 5 мин, крупные от 3×, у цены ближе 0,35% —
выделение сильнее.

## Алерты

События: съели плотность (по порогу), всплеск объёма 5м (от 3× и 300 тыс $),
хай/лой дня, новый сетап по тренду с R:R от 1:3. Отдельные алерты — только
по монетам «в игре» (топ роста, движение от 5%, NATR 1ч от 1,5%, свежий
всплеск); остальные хай/лой — сводкой раз в 30 мин; лимит 60 в сутки.

В каждом алерте: картинка графика с наклонными, уровнями и плотностями, два
сценария с процентами, строка «1:3 по тренду» (вход, стоп за опорой не ближе
0,4%, цель — первое препятствие за 3R: перехай, уровень, трендовая, Фибо,
плотность), контекст монеты и ссылка «открыть в скринере». По каждой сделке
из алерта приходят отработки ответом на исходное сообщение: +1R, +2R, цель,
стоп.

## Как запустить и выкатить

```bash
# на ВМ: обновить код и перезапустить контур (systemd поднимет сам)
cd /opt/crypto-screener && git pull --ff-only origin claude/screener-board
kill -TERM $(systemctl show screener -p MainPID --value)

# маршрут вебхука в Caddy (один раз, от root)
sudo bash /opt/crypto-screener/tools/deploy/caddy_hook.sh
```

Настройки: `/opt/crypto-screener/.env` (`TELEGRAM_BOT_TOKEN`,
`TELEGRAM_PROXY`, `SCREENER_ALERT_CHAT`), `data/watchlist.txt` (монеты
вне порога оборота, сейчас GTC и MARSCOIN), `data/dens_rules.json`.
Профили ботов — `/opt/crypto-trade/data/trade/screener-profiles.json`.

# Страница ботов: оформление и прокрутка

Опубликовано 06.10.2026, 23:36 МСК на `/bots.html`, включая `#screener-alerts`.

Причины неудобства: фиксированная высота встроенных вкладок (85vh) создавала вложенную вертикальную прокрутку; минимальная ширина содержимого расширяла двухколоночную сетку; длинные описания отодвигали открытые позиции вниз. Нижняя горизонтальная полоса была неудобна при большом числе позиций.

Изменения:

- Сводка из шести карточек: капитал, торговый результат, доходность без пополнений, просадка, открытые позиции, закрытые сделки. На узком экране — две колонки.
- Открытые позиции расположены перед справкой. PnL USDT, PnL %, доля капитала, стоп/тейк и выход сохранены.
- Правила, подробная статистика и разбор результатов раскрываются отдельно. Данные не удалены.
- Сетка ограничивает ширину дочерних блоков. Широкие таблицы прокручиваются внутри доступной ширины; монета закреплена слева в открытых позициях. Над таблицами позиций и закрытых сделок есть синхронная горизонтальная полоса.
- Вкладки профилей оформлены карточками в горизонтальном ряду. URL-фрагменты сохранены.
- Высота встроенной страницы считается по маркеру конца содержимого; пересчитывается при смене вкладки, размера окна и раскрытии/сворачивании разделов. Вертикальная прокрутка остаётся у внешней страницы. При недоступном содержимом сохраняется обычное поведение iframe.

Проверено: 43 теста торгового состояния/управления/пополнений; JS-проверка расширения и уменьшения высоты, скрытой вкладки и её активации; HTTPS 200, новая разметка всех семи профилей, синтаксис 15 опубликованных скриптов и новая версия общих ресурсов. Четыре проверенные службы активны после перезапуска монитора.

Визуальная проверка через встроенный браузер заблокирована `ERR_BLOCKED_BY_CLIENT`. Пиксельная проверка на компьютере пользователя и фактическое поведение прокрутки мышью ещё не подтверждены.

Развёртывание: `deployment/deploy_bots_layout.py`; проверка: `deployment/verify_bots_layout.py`. На сервере сохранены копии изменённых файлов с суффиксом `.before-bots-layout-20261006-233558`. Обновлены только генераторы HTML и общие UI-ресурсы; перезапущен `screener-monitor.service` для загрузки генераторов. Настройки торговли и журналы сделок не редактировались. Для отката восстановить эти копии и перезапустить монитор.

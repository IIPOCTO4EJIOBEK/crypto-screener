# crypto-screener

ИИ-ассистент для поиска монет и точек входа: скринер по формациям и
плотности стакана, база данных, RAG по методике, предложения входа с
описанием стратегии и её отработки.

Проект личный, приватный. Торговля идёт через **Tiger.com Broker** —
прослойку-агрегатор над Binance, Bybit, OKX, Hyperliquid, Bitget, Gate.

## Что важно понимать

1. **Ключ не нужен для скринера.** Стаканы, свечи и лента сделок —
   публичные данные. Приватный ключ требуется только под баланс и позиции,
   это отдельный слой.
2. **Binance и Bybit недоступны из РФ напрямую** (451 и 403). Tiger даёт к
   ним дорогу только через свой терминал. Скринер строится на биржах,
   доступных напрямую, с единым интерфейсом — источник данных подменяем.
3. **Стратегия описывается правилами, а не настройками.** У каждой формации
   есть определение, критерии подтверждения, вход, стоп, цель и условие
   отмены — они лежат в `src/analysis/` и проверяются тестами.
4. **Числа считает код, а не модель.** Расчёты уровней, плотности,
   доходности и риска выполняются в коде; языковая модель объясняет
   результат и формулирует предложение, но не считает сама.
